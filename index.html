⚡ ChargeMate Changelog
v2.4 25 Jun 2026
  • Dead CSS purge: Removed ~10 KB of unused theme variables (qw-theme, graph, QuickSight) — faster load on WebView APK
  • Undo delete: Deleting charges, trips, or carpool entries now shows a 5-second "Undo" toast instead of confirm() dialog
  • Android back button: Navigates between tabs instead of exiting the app in WebView
  • Service worker v2: Cache-first with versioned cache — old caches auto-purged on update, true offline support
  • Backup reminder: Now triggers at 7 days (was 30), only if >5 sessions logged
v2.3 24 Jun 2026
  • At a Glance: Replaced "Total Charged" with "Last Charged" (date + type) — session counts misleading with partial logging. Added "Cost / km".
  • Spending: Renamed from "Paid Charging". Generic layout — This Month, Total, ₹/kWh, Avg/Session. No home/public split assumption.
  • Settings: Vehicle + Petrol merged into one card (2-column rows). Backup Export/Import on one line.
  • Removed: Sessions/Week, duplicate Est. Range from At a Glance
v2.2.1 24 Jun 2026
  • Carpool card: 4 stats (Total Income, This Month, Net Cost, Avg/Trip). "Charge Breakdown" split bars moved to own card.
  • Bug fixes: ₹ values rounded (no decimals), negative Net Cost shows "surplus" in green, session counts removed from stat values
v2.2 24 Jun 2026
  • Dashboard redesign: Replaced Overview + Cost Metrics + Habits with focused cards — At a Glance, Spending, Carpool, Charge Breakdown, Range, Chart
  • Carpool auto-sum: Enter expressions like 100+110 in Amount — live "= ₹210" preview, saves computed total, shows expression on edit
  • Removed: Charging Summary from Charges tab, Petrol Saved metric, 4× per-km cost variants
v2.1.2 22 Jun 2026
  • Carpool distance fix: km now derived from Settings at save time (not form state). Fixes "randomly missing distance" bug — first entry after page load was always empty.
  • Carpool field: Distance hidden again (pulled from Settings silently)
v2.1.1 22 Jun 2026
  • Critical fix: Efficiency calculation completely rewritten — charges now produce arrival (start%) + departure (end%) waypoints. Consolidates multiple charges at same odo.
  • Trip date: Defaults to today
  • Missed charge flag: Added to charge form (was only on trips)
  • Settings: Merged Import+Export into single Backup card, removed CSV export
v2.1 22 Jun 2026
  • Regen support: Trips can now have end% ≥ start% for downhill regen driving
  • Timeline logic: % increase + odo increase = regen (valid driving), % increase + same odo = charge (breaks chain)
  • Regen display: Shows "⚡ X km · +Y% regen · Z kWh recovered" in list and preview
  • Stats: Regen km counted in total distance, consumption neutral (0) for avg calculation
v2.0.1 22 Jun 2026
  • Bug fix: Tabs 3–5 (Carpool, Plan, Settings) were blank due to unclosed div in Charges section
  • Odo mandatory: All entries require odometer reading (no more optional)
  • Same-odo sort fix: Correct timeline ordering when trip ends and charge starts at same odometer
  • Efficiency warnings: Adaptive flags at 1.5× avg (⚠️) and 2× avg (⚠️ missed charge?) — excluded from dashboard avg and chart
  • Cleanup: Removed all dead time picker CSS remnants
v2.0 22 Jun 2026
  • Trip Logger: New entry mode — log trips with Start/End Odo + Start/End % for self-contained efficiency tracking
  • Unified Timeline: Efficiency computed from all waypoints (charges + trips) sorted by odometer
  • Charged Since flag: Mark trips where an unlogged charge happened — breaks the efficiency chain
  • Time inputs removed for Office/Home: No taper detected (5.5 %/hr flat), timestamps unnecessary
  • Auto-duration: Office/Home charges show estimated duration based on 5.5 %/hr constant rate
  • Native time picker: Public charges use browser's native time input (removed custom popup picker)
  • Chart fix: requestAnimationFrame for reliable rendering
  • Export/Import includes trips array (backward compatible with older backups)
  • Entry mode toggle: Charge ⚡ vs Trip 🚗 pill selector
